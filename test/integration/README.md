# Hyphae End-to-End Integration Test Suite

Comprehensive, zero-cloud-cost integration tests exercising real Hyphae routers, multi-connector daemons, signed webhook streams, bridge plugins, virtual harness environments (OpenClaw, Herdr Core, T3 Code), multi-host emulation (TLS, network partitions, virtual SSH), and real installed AI harness CLI binaries on `127.0.0.1`.

Applies William M. McKeeman's **Differential Testing for Software** (1998) methodology (see [AGENTS.md](../../AGENTS.md)): comparable cross-harness post-state checks, perturbed/nearby-altered inputs, forgotten CLI/env/permission inputs, and nondeterminism filtering.

## Running

```bash
npm run test:integration
```

Or run any single suite:

```bash
node --test test/integration/network-topology.test.ts
node --test test/integration/webhooks-and-bridges.test.ts
```

## Architecture & Shims

Every test spins up an isolated `MeshTopology` ([harness/topology.ts](./harness/topology.ts)) backed by short ephemeral temp directories (`hi-...` to stay well under macOS's 104-byte Unix socket `SUN_LEN` limit), `127.0.0.1` `port: 0` bindings, and guaranteed teardown in `finally`:

- **Scripted Local LLM API Shims** ([shims/llm.ts](./shims/llm.ts)):
  - `startScriptedAnthropicServer` (`/v1/messages` SSE + JSON, `/v1/messages/count_tokens`) for real `claude` CLI.
  - `startScriptedOpenAIResponsesServer` (`/v1/responses` SSE) for real `codex` CLI and real `opencode` v2 CLI.
  - `startScriptedGeminiServer` (`/v1beta/models/<model>:streamGenerateContent?alt=sse`) for real `agy` (Antigravity CLI).
  - Deterministic turn-by-turn `TurnContext` helpers (`findTool`, `callTool`, `callOpenCodeTool`, `callAgyMcpTool`, `selectClaudeTools`, `hasText`, `reply`) with full turn transcripts on assertion failure.
- **External Service Shims** ([shims/services.ts](./shims/services.ts)):
  - **GitHub Webhooks**: Signed & tampered `X-Hub-Signature-256` payloads delivered to Hyphae's built-in `github-webhook` stream.
  - **Prometheus / Alertmanager**: Signed & tampered `X-Webhook-Signature-256` alerts delivered to `webhook-stream` / `prometheus-webhook`.
  - **Mock Slack Socket Mode Server**: Zero-dependency `127.0.0.1` HTTP (`auth.test`, `apps.connections.open`, `chat.postMessage` with fault injection) + RFC 6455 WebSocket server driving the real `plugins/slack/index.mjs` bridge via `SLACK_API_BASE` and `0600` `{ "secret": "..." }` tokens.
  - **Mock Telegram Bot API Server**: Loopback `POST /bot<token>/getUpdates` long-polling + `POST /bot<token>/sendMessage` server (with fault injection) driving the real `plugins/telegram/index.mjs` bridge via `TELEGRAM_API_BASE` and `0600` `{ "secret": "..." }` tokens.
- **Virtual Secret Service Shim** ([shims/secret-service.ts](./shims/secret-service.ts)):
  - `startVirtualSecretService`: cross-platform executable `secret-tool` wrapper backed by atomic temp-dir state + invocation argv log + fault injection, allowing full `HYPHAE_SECRET_BACKEND=secret-service` CLI, daemon, and `{ secretFile }` `.runtime/*.secret` materialization testing on both macOS and Linux without D-Bus.
- **Multi-Host Emulation Shims** ([shims/multihost.ts](./shims/multihost.ts)):
  - `startTlsReverseProxy`: ephemeral self-signed localhost CA + `node:https` streaming reverse proxy for `https://` origin validation, invites, `probeRouter`, and SSE over TLS (`NODE_EXTRA_CA_CERTS`).
  - `startChaosProxy`: loopback HTTP/SSE proxy with `sever()`, `heal()`, and `setLatencyMs()` to simulate single-host network partitions while the router and other connectors stay live.
  - `createVirtualSshHost`: isolated `bin/ssh` + `hyp` wrapper mapping remote SSH commands into a separate virtual `HOME`/`XDG_CONFIG_HOME` to test `probeRemoteHost` and `onboardRemoteOverSsh` end-to-end.
- **Virtual Harness Environments**:
  - [shims/openclaw-env.ts](./shims/openclaw-env.ts): `VirtualOpenClawEnv` booting the exact `mcp.servers.hyphae` command generated by `setupOpenClaw`.
  - [shims/herdr-env.ts](./shims/herdr-env.ts): `startVirtualHerdrServer` stateful mock `hc` CLI controller exercising real `daemon.ts` / `delivery.ts` `queue` vs `interrupt` actuation, PID/guard safety, and `hc machine ls` discovery.
  - [shims/t3-env.ts](./shims/t3-env.ts): `startRealT3Server` (isolated `t3 serve --base-dir`), `seedVirtualT3MeshHome`, `startVirtualCodexCli` (`codex queue --thread --remote --resume`), and `openRouterInboxSse`.

## Strict Isolation Guarantees

- Tests **never** touch `~/.config/hyphae`, `~/.claude`, `~/.codex`, `~/.gemini`, `~/.config/opencode`, `~/.cursor`, `~/.openclaw`, `~/.t3`, `~/.t3-mesh`, or live Herdr tabs.
- Every real harness CLI is launched with isolated `HOME`, `XDG_CONFIG_HOME`, `XDG_DATA_HOME`, `XDG_CACHE_HOME`, `XDG_STATE_HOME`, `CODEX_HOME`, `T3CODE_HOME`, and stripped `HC_TERMINAL_ID` / `ANTIGRAVITY_SOURCE_METADATA` / `CLAUDE_SESSION_ID` / `CODEX_THREAD_ID`.
- Zero real cloud API calls and zero API token cost.

## Updating Shims When Harness CLIs Upgrade

- **Claude Code (`claude`)**: Configured via `ANTHROPIC_BASE_URL` + `--mcp-config --strict-mcp-config --settings --no-session-persistence`. Update `selectClaudeTools` or `startScriptedAnthropicServer` ([shims/llm.ts](./shims/llm.ts)) and flags in `runRealClaude` ([harness/drivers.ts](./harness/drivers.ts)).
- **Codex CLI (`codex`)**: Configured via `-c model_providers.dummy.base_url=...` + `wire_api="responses"` and isolated `CODEX_HOME`. Update `startScriptedOpenAIResponsesServer` ([shims/llm.ts](./shims/llm.ts)) or `createRealCodexRunner` ([harness/drivers.ts](./harness/drivers.ts)).
- **OpenCode (`opencode`)**: Configured via `providers.openai.settings.baseURL` in isolated `XDG_CONFIG_HOME/opencode/opencode.json` + `opencode run --standalone --auto`. OpenCode v2 exposes MCP servers through Code Mode (`execute` calling `tools.hyphae.<tool>(args)`) and loads plugins exporting `{ id, setup(ctx) }` with `ctx.tool.hook("execute.before" | "execute.after", ...)`. Update `runRealOpenCode` ([harness/drivers.ts](./harness/drivers.ts)) or `setupOpenCode` (`src/setup.ts`).
- **Antigravity (`agy`)**: Configured via `GOOGLE_GEMINI_BASE_URL` + `GEMINI_API_KEY` + `--settings '{"modelProvider":"gemini"}'` and an isolated `HOME` plugin generated by `setupAntigravity`. Plugin MCP tools are lazily exposed under server name `hyphae_hyphae` via `call_mcp_tool` and authenticated per-call via `PreToolUse` `overwrite._meshCall`. Update `startScriptedGeminiServer` ([shims/llm.ts](./shims/llm.ts)) or `runRealAgy` ([harness/drivers.ts](./harness/drivers.ts)).
- **Cursor (`cursor-agent`), Herdr (`hc`), T3 Code (`t3`)**: Real binary discovery / side-by-side server boot / fail-closed checks are paired with stateful loopback virtual environment shims (`herdr-env.ts`, `t3-env.ts`) and hook/MCP protocol tests.
